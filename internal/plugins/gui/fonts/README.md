# IBM Plex Mono

The window draws its text in IBM Plex Mono, so that it looks like the web view
of the same GUI on a desktop whose monospace face is iA Writer Mono (a
modified IBM Plex Mono) without embedding that face, which is not
redistributable.

The four faces (regular, bold, italic, bold italic) are embedded so that the
window looks the same on every machine. IBM Plex Mono is by IBM and licensed
under the SIL Open Font License 1.1; see LICENSE.
